# raDT — Relate Assemblies for Defence Technology

Исследовательский проект применения RA, raFTI, raSS и raHE к структурному сопоставлению, целостности данных и семантической интеграции технических реестров.

Статус: концепция и исследование. Репозиторий приватный.

## Структура

- `docs/concept/` — концепции и версии документов
- `docs/history-1995/` — история проекта Konkurs-TM
- `docs/research/` — исследования, обсуждения, источники
- `data/sources/` — описание источников данных
- `data/benchmarks/` — тестовые наборы и эталонные соответствия
- `src/bridge/` — прототип интеграции реестров
- `src/equivalence/` — прототип сопоставления аналогов
- `src/Konkus_TM/` — исторические исходники тренажёра
- `tests/` — тесты

Документы и гипотезы в репозитории не означают подтверждённой работоспособности прототипа.
